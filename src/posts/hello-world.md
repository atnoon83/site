这是这个博客的第一篇文章。

## 为什么又要写博客

上一次认真写东西，还是在笔记软件里自说自话。笔记越攒越多，却没有一篇是「可以给别人看」的。
所以这次换一种方式：把想清楚的事情写完整一点，发出来。

写作有个好处——**你会发现自己其实没想明白**。脑子里的想法是模糊的，落到句子上就必须做选择：
先讲什么、后讲什么、这个结论到底靠不靠得住。写不下去的地方，通常就是理解不到位的地方。

## 这里会写什么

计划大概分几类：

- 技术笔记：踩过的坑、读过的源码、做过的取舍
- 阅读记录：书里值得记下来的段落和想法
- 一些随笔：和代码无关，但想写下来的东西

不保证更新频率，但保证每篇都尽量写完，不发半成品。

## 关于这个站

这个站是用 SvelteKit 和 TypeScript 写的，构建时静态预渲染，文章是 Markdown 文件。
写得越简单，越不容易停更——这是过去几年最实在的教训。

> 写博客最难的不是写，而是开始写。所以这篇就短一点，先开始。

## 一个小例子

文章里可以直接写代码，构建时会做语法高亮：

```ts
interface Post {
	title: string;
	date: string;
	tags: string[];
}

export function formatDate(iso: string): string {
	const [year, month, day] = iso.split('-').map(Number);
	return `${year}年${month}月${day}日`;
}
```

行内代码也没问题，比如 `npm run dev`。
